# Python Analysis

This folder contains the Python analysis for the **Retail Demand Intelligence** project.

The Python layer extends the SQL analysis into statistical testing, time-series analysis, anomaly detection, forecasting, and model evaluation.

---

## Objectives

The Python analysis was used to:

- Understand daily revenue trends
- Identify weekly demand patterns
- Measure rolling revenue volatility
- Detect unusual revenue observations
- Statistically test business assumptions
- Compare forecasting approaches
- Validate forecasting models on unseen data
- Select the best-performing model
- Generate 30/60/90-day revenue forecasts
